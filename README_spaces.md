# Enhanced Pneumonia Detection with Explainable AI

🫁 AI-powered chest X-ray pneumonia detection with comprehensive explainable AI features including Grad-CAM, LIME, SHAP, and interactive web interface.

- Pneumonia detection using pre-trained CNN
- Grad-CAM attention visualization
- LIME superpixel explanations  
- SHAP feature importance
- Professional probability dashboard
- Automated HTML reporting
